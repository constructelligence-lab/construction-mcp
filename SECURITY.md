# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use a
[private security advisory](https://github.com/constructelligence-lab/construction-mcp/security/advisories/new)
and include what you found, how to reproduce it and what you think the impact is.

We aim to acknowledge reports within a week. This is a small open source project: there is no bug bounty and
no guaranteed fix time, but reports are taken seriously and credited if you wish.

## Scope

This project is code that runs on your machine; reports about unsafe handling of input, file access or network use are in scope.
